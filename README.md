# PM2.5 Measurement System

## Overview

This project is a PM2.5 measurement system developed to monitor particulate matter in various environments.

The system uses a particle sensor and microcontroller to measure PM1.0, PM2.5, and PM10 concentrations.

## Purpose

I developed this device after becoming interested in air quality during electronic work activities.

The goal was to measure particulate matter generated in daily environments and investigate factors affecting air quality.

## Features

- Measurement of PM1.0, PM2.5, and PM10
- Real-time particle concentration monitoring
- Data collection in different environments
- Investigation of particle generation sources

## Measurement Targets

The system was used to measure particulate matter generated during:

- Soldering activities
- Cooking processes
- Heating devices
- Other indoor activities

## Hardware

- Arduino UNO R3
- ZH03B PM sensor
- Electronic components

## Software

- Arduino IDE
- C/C++

## Experiment

Measurements were performed in different conditions to compare changes in particulate matter concentration.

The effects of ventilation were also investigated.
